# Arcane Ward

Arcane Ward is a RuneLite plugin that changes the local appearance of
Elidinis' ward (f) and Elidinis' ward (or).

Available appearances:

- Original ward
- Arcane spirit shield
- Arcane spirit shield (or)
- Arcane spirit shield (f)

Choose an appearance in the plugin settings or right-click the equipped ward
to cycle between them. New installations default to Arcane spirit shield (f),
and RuneLite remembers the last selection.

This plugin is cosmetic only. It does not change item stats, interactions, or
game state, and its appearance changes are visible only on your client.

## Building

The project requires Java 11 or newer.

```text
./gradlew build
```
